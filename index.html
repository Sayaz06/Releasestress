📖 Jana Pukal v2 — Format Ayat
Tampal teks berformat untuk jana laci secara automatik
📌 Format Wajib
surah : [nombor].[nama surah]

ayat [nombor]
teks arab : [ayat dalam tulisan arab]
penerangan : [maksud atau huraian]

ayat [nombor seterusnya]
teks arab : ...
penerangan : ...
✅ Contoh Lengkap
surah : 1.Al-Fatihah

ayat 1
teks arab : بِسْمِ ٱللَّهِ ٱلرَّحْمَـٰنِ ٱلرَّحِيمِ
penerangan : Dengan nama Allah Yang Maha Pengasih lagi Maha Penyayang

ayat 2
teks arab : ٱلْحَمْدُ لِلَّهِ رَبِّ ٱلْعَـٰلَمِينَ
penerangan : Segala puji bagi Allah, Tuhan sekalian alam
⚠️ Nota Penting
• Gunakan tanda titik dua ( : ) selepas setiap kata kunci
• Kata kunci: surah, ayat, teks arab, penerangan
• Besar kecil huruf tidak penting — "Surah" atau "SURAH" sama sahaja
• Setiap ayat mesti bermula dengan "ayat [nombor]" pada baris sendiri
• Kosongkan "teks arab" atau "penerangan" jika tiada — masukkan sahaja kata kunci dengan nilai kosong
• Boleh salin terus dari Google Docs atau Notepad
• Satu paste boleh jana sehingga 499 ayat sekaligus
🔄 Cara Guna
1️⃣ Buka Google Docs atau Notepad
2️⃣ Taip ayat ikut format di atas
3️⃣ Salin semua teks (Ctrl+A → Ctrl+C)
4️⃣ Kembali ke app, tekan 📖 Jana Pukal v2
5️⃣ Tampal teks (Ctrl+V atau tekan lama → Tampal)
6️⃣ Semak bilangan ayat dijumpai di bawah kotak
7️⃣ Tekan ⚡ Jana Sekarang

📘 Panduan Pengguna
• Format Kamus (Laci Fakta):
Guna format Perkataan = Maksud dalam satu kotak.
(Cth: Alhamdulillah = Segala Puji Bagi Allah)

• Format Rutin Wirid:
Zikir, Target Mini, dan Maksud kini telah diasingkan ke dalam 3 kotak berbeza.

• 5 Mode Pembelajaran (Fakta):
1. Normal: Klik kotak paparan untuk lihat terjemahan.
2. Repeat: Ulang sebelum ke fakta seterusnya.
3. Rest: Mod fokus bertukar sasaran 33/17 & rehat minda.
4. Combo: Sapu/Enter paparkan maksud. Sekali lagi ke laci baru.
5. Super: Sama seperti Combo, tapi bacaan audio dimainkan.

• Shortcut:
Tekan Enter / NumpadEnter atau Sapu Skrin (Swipe) atas/bawah untuk zikir pantas tanpa menyentuh bulatan tengah.
